# Percona Server for MySQL, Percona XtraDB Cluster, and Percona Distribution for MySQL 8.4.12, 9.7.3, 8.0.46, and 5.7.44 have been released

<!-- more -->

!!! note "A note on MySQL 8.4.12 and 9.7.3"

    The 8.4.12 and 9.7.3 releases are not based on the MySQL 8.4.12 and MySQL 9.7.3 releases. MySQL 8.4.12 and 9.7.3 are Critical Security Patch Updates (CSPUs) — targeted security releases that Oracle can issue between quarterly Critical Patch Updates (CPUs) when needed. These CSPUs apply to the MySQL Server Docker image only, and their fixes do not affect Percona Server for MySQL or Percona XtraDB Cluster.

The following releases of Percona Server for MySQL, Percona XtraDB Cluster, and Percona Distribution for MySQL have been released on Thursday, November 12, 2026.

All these releases include a fix for [PS-11950](https://perconadev.atlassian.net/browse/PS-11950){:target="_blank"}: `mysqldump` could write wrong table definitions for tables with compressed columns, and did not correctly handle some compression dictionary names and data.
