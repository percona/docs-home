# Percona Search for MongoDB 1.70.5-3 is generally available

<!-- more -->

[Percona Search for MongoDB](https://docs.percona.com/percona-search-for-mongodb/){:target="_blank"} 1.70.5-3 has been released on October 29, 2026.

Percona Search for MongoDB is now generally available and supported for production use. You can use full-text search, vector search, and automatic embedding on your production Percona Server for MongoDB deployments.

This release adds the Hugging Face Inference API as an automatic embedding provider, alongside Voyage AI and OpenAI-compatible services. You can generate embeddings using hosted models without running your own embedding server. The Hugging Face provider supports embedding tasks only.

Get started with the [installation guide](https://docs.percona.com/percona-search-for-mongodb/install-mongot.html){:target="_blank"}.

Learn more in the [Percona Search for MongoDB 1.70.5-3 release notes](https://docs.percona.com/percona-search-for-mongodb/release_notes/1.70.5-3.html){:target="_blank"}.
