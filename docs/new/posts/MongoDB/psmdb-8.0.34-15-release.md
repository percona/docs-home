# Percona Server for MongoDB 8.0.34-15 has been released

<!-- more -->

[Percona Server for MongoDB](https://docs.percona.com/percona-server-for-mongodb/8.0/){:target="_blank"} 8.0.34-15 has been released on October 22, 2026.

This release includes improvements, bug fixes, and security fixes from MongoDB Community Edition 8.0.34. It also fixes a failure when streaming backups to Google Cloud Storage through its S3-compatible API.

If you install from binary tarballs, download MongoDB Database Tools separately: they are no longer bundled in the server tarball. RPM and DEB installations continue to install these tools as before.

Follow the [minor upgrade guide](https://docs.percona.com/percona-server-for-mongodb/8.0/install/minor-upgrade.html){:target="_blank"} to update your deployment.

Learn more in the [Percona Server for MongoDB 8.0.34-15 release notes](https://docs.percona.com/percona-server-for-mongodb/8.0/release_notes/8.0.34-15.html){:target="_blank"}.
