# Percona Toolkit v3.7.2 has been released

<!-- more -->

[Percona Toolkit v3.7.2](https://docs.percona.com/percona-toolkit/){:target="_blank"} has been released on Thursday, October 22, 2026.

This release includes major improvement for the `pt-k8s-debug-collector` tool, improvements for `pt-mongodb-summary`, `pt-kill`, better MariaDB support, removal of deprecated tool `pt-slave-delay`, and bug fixes.

Learn more in the Percona Toolkit v3.7.2 [release notes](https://docs.percona.com/percona-toolkit/release_notes.html#v3-7-2-released-2026-10-22){:target="_blank"}.
